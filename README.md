# Врата расширений

Каталог расширений для SillyTavern в мрачной эстетике «Адской девочки»: чёрный и алый, красная нить, лепестки, поле «впиши имя».

Чистый HTML/CSS/JS, без сборки и зависимостей.

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | разметка страницы |
| `style.css` | весь дизайн |
| `script.js` | поиск, фильтры, модалка, анимации |
| `data.js` | **список расширений — правишь только его** |

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub (например `extensions`).
2. Загрузи все файлы в корень (Add file → Upload files).
3. Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → Save.
4. Через минуту-две сайт будет по адресу `https://USERNAME.github.io/extensions/`.

## Как добавить расширение

Открой `data.js`, скопируй любой блок `{ ... }` и поменяй поля:

```js
{
  name: "Моё расширение",
  by: "ник",
  desc: "Что оно делает.",
  tags: ["Память"],
  repo: "https://github.com/USERNAME/REPO"
}
```

Фильтры по тегам строятся автоматически.

## Что поменять под себя

- Цвета — переменные в начале `style.css` (`--blood`, `--crimson`, `--ink`).
- Название и тексты — `index.html`.
- Надписи иероглифами (`拡張`, `一覧`, `手順`, `序`, `終`) — просто декор, можно заменить на любые.
