Как установить

  1. I

    Открой SillyTavern

    Перейди во вкладку Extensions (значок с кубиками).

  2. II

    Install extension

    Нажми Install extension вверху панели расширений.

  3. III

    Вставь ссылку

    Скопируй ссылку на репозиторий с карточки и вставь в окно установки.

О месте

Это тихий уголок для расширений SillyTavern. Здесь нет суеты — только список того, что можно подключить к своим историям.

Говорят, по ночам здесь бродит лиса. Если увидишь голубой огонёк, иди за ним: он ведёт к нужному расширению.

Неофициальный фан-проект: вдохновлён эстетикой аниме, не связан с правообладателями и не использует их материалы.
