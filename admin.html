Подключение

Где взять токен
  1. Открой создание токена.
  2. Repository access → Only select repositories → выбери репозиторий сайта.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate token, скопируй и вставь сюда.

Токен хранится только в твоём браузере и отправляется только на api.github.com. Без него эта страница ничего не умеет, так что посторонние ничего не изменят.

Каталог

    После сохранения сайт обновляется примерно через минуту.

    Новое расширение

    Источник

    Вставь ссылку: название, автор, описание и прочие теги заполнятся сами. Главный тег выбери сам. Всё можно поправить.

    Основное
    Категория и теги

    Главный тег — это кнопка-фильтр на сайте, он один. Остальные уйдут в раздел «Прочее» и не будут засорять каталог.

    Картинки

    До 8 штук. Первая показывается на карточке; чтобы сделать другую первой — нажми на неё. Перед загрузкой сжимаются в webp.
