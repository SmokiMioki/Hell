управление каталогом

1 · Подключение

Где взять токен
  1. Открой создание токена.
  2. Repository access → Only select repositories → выбери репозиторий сайта.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate token, скопируй и вставь сюда.

Токен хранится только в твоём браузере и отправляется только на api.github.com. Без него эта страница ничего не умеет, так что посторонние ничего не изменят.

2 · Добавить расширение

Вставь ссылку: название, автор, описание и теги заполнятся сами. Всё можно поправить.

3 · Уже в каталоге

    После сохранения сайт обновляется примерно через минуту.
